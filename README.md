# AutoPC

A self-learning PC automation agent powered by the **Claude Agent SDK**.

AutoPC looks at the screen, reasons about the next step, and acts with a real
mouse and keyboard - then *remembers what it learned* and *crystallizes
successful work into reusable skills*, so it gets faster and more reliable the
more it is used.

It combines two lineages:

- A kernel-level **body** and a Claude Agent SDK **brain** - precise,
  DPI-correct perception and physical input that drives the actual desktop.
- A **memory** and **skill-learning** layer in the style of MemGPT/Letta and
  the Hermes agent - persistent facts the agent edits itself, and `SKILL.md`
  playbooks distilled from its own successful runs.
